## Suggested learning order (30–45 min)

1. Read the 5-year-old nutshell (2 min)
2. Read the mental-model blog (15–20 min)
3. Run the code example: start a wait, then post from another tab (10–15 min)
4. Copy/adapt the LinkedIn post and share what clicked for you (5 min)

## One-line takeaway

**Long polling = the client asks “tell me when something is new” and the server holds that HTTP request until there is news or a timeout.**
