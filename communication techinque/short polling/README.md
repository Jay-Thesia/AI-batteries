# Short Polling Learning Pack

All material for learning **short polling** lives in this folder.

| File | What it is |
|---|---|
| [00-nutshell-for-a-5-year-old.md](./00-nutshell-for-a-5-year-old.md) | Ultra-simple explanation |

## Suggested learning order (30–45 min)

1. Read the 5-year-old nutshell (2 min)
2. Read the mental-model blog (15–20 min)
3. Run the code example and watch empty polls vs a new message (10–15 min)
4. Copy/adapt the LinkedIn post and share what clicked for you (5 min)

## One-line takeaway

**Short polling = the client asks “anything new?” on a timer and the server answers immediately, even when the answer is “no.”**
