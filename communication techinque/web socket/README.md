| File | What it is |

## Suggested learning order (30–45 min)

1. Read the 5-year-old nutshell (2 min)
2. Read the mental-model blog (15–20 min)
3. Run the code example: open two browser tabs and chat (10–15 min)
4. Copy/adapt the LinkedIn post and share what clicked for you (5 min)

## One-line takeaway

**WebSocket = upgrade HTTP once, then both sides send frames whenever they want on the same long-lived connection.**
