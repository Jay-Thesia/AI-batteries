## Suggested learning order (30–45 min)

1. Read the 5-year-old nutshell (2 min)
2. Read the mental-model blog (15–20 min)
3. Run the code example and try all 4 queries (10–15 min)
4. Copy/adapt the LinkedIn post and share what clicked for you (5 min)

## One-line takeaway

**GraphQL = client writes a wishlist for data; server returns exactly that shape from one schema-powered endpoint.**
